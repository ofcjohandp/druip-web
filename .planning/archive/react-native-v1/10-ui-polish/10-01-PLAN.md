<objective>
Remove all fontFamily + fontWeight conflicts across the entire codebase. In React Native, when a StyleSheet object sets both `fontFamily` (e.g. `Nunito_400Regular`) AND `fontWeight`, the OS cannot find the correct font variant — it falls back to the system font and stretches or ignores the weight. This plan audits every file found to contain `fontWeight` and either removes `fontWeight` (when a named Nunito/Syne font variant already encodes the weight) or adds the correct `fontFamily` (when no fontFamily is set, meaning system font is intentional).

Purpose: Fix the visible font distortion Johan saw on device — "Morning, Test" and section titles appeared stretched.
Output: Zero fontFamily+fontWeight conflicts in any StyleSheet across src/.
</objective>
