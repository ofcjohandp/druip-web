   - Import `Pressable` from 'react-native'
   - Import `Animated, { useSharedValue, useAnimatedStyle, withSpring }` from 'react-native-reanimated'

   - Create `const animatedStyle = useAnimatedStyle(() => ({ transform: [{ scale: scale.value }] }))`

   - Inner element: `<Animated.View style={[styles.base, variantStyle, animatedStyle, style]}>`
   - Inside Animated.View: conditional render — if loading, `<ActivityIndicator size="small" color={variant === 'primary' ? COLORS.textOnAccent : COLORS.accent} />`; else, optional icon + title text

**Card.tsx** — extend per D-09:

1. Add optional props (non-breaking):
   - `elevated?: boolean` — when true, adds shadow styles
   - `pressable?: boolean` — when true, wraps in Pressable + Reanimated scale
   - `onPress?: () => void` — callback for pressable mode

2. Shadow styles for elevated (per Research Pattern 6):
```typescript
const elevatedStyle: ViewStyle = {
  shadowColor: '#000',
  shadowOffset: { width: 0, height: 3 },
  shadowOpacity: 0.10,
  shadowRadius: 8,
  elevation: 4,
};
```

3. Card background: use `COLORS.card` (white) instead of `COLORS.surface` — per D-03, cards should pop against the cream background.

4. Pressable mode: same Reanimated pattern as Button — `useSharedValue(1)`, `useAnimatedStyle`, `withSpring(0.97)` on press. Only create shared values when `pressable=true` (always create them — hooks can't be conditional, but only attach the Pressable wrapper when pressable is true).

Implementation note: Always call `useSharedValue(1)` and `useAnimatedStyle` (hooks must be unconditional). If `pressable`, wrap in `<Pressable>` + `<Animated.View>`; if not, render plain `<View>`.
