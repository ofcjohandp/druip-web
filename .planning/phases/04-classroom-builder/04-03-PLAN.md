**File 1: `src/features/classroom/uploadClassroomFile.ts`**

Two exports:

**1. uploadClassroomFile(classroomId: string, fileUri: string, fileName: string, mimeType: string): Promise&lt;string&gt;**
- Convert URI to Blob: `const response = await fetch(fileUri); const blob = await response.blob();` (per Research Pitfall 2 — cannot pass fileUri directly)
- Storage path: `` `${classroomId}/${Date.now()}-${fileName}` ``
- Upload: `supabase.storage.from('classroom-assets').upload(storagePath, blob, { contentType: mimeType })`
- If error, throw
- Return `storagePath` (string, not URL)

Note: sort_order is append-only for cards in v1.0 — card reorder is deferred per CONTEXT.md Deferred Ideas. Cards get sort_order computed as `Math.max(...cards.map(c => c.sort_order), 0) + 1000` and are never reordered.

**2. getSignedUrl(storagePath: string): Promise&lt;string&gt;**
- `supabase.storage.from('classroom-assets').createSignedUrl(storagePath, 3600)` (1-hour expiry per D-17)
- If error, throw
- Return `data.signedUrl`

NEVER use `getPublicUrl` — bucket is private. Always `createSignedUrl`.

```typescript
import { supabase } from '@/lib/supabase';
```

**File 2: `src/features/classroom/useClassroomCards.ts`**

Five exports. All use query key `['classroom-cards', sectionId]`.

**1. useClassroomCards(sectionId: string | undefined)**
- Fetches from `classroom_cards` filtered by `section_id`, ordered by `sort_order` ascending
- `enabled: !!sectionId`
- For each card with `card_type === 'pdf' || card_type === 'image'` and a non-null `storage_path`, also generate signed URL by calling `getSignedUrl(card.storage_path)` and attach as `signedUrl` property
- Return type: `(CardRow & { signedUrl?: string })[]`

**2. useCreateTextCard(sectionId: string)**
- Mutation inserts `{ section_id: sectionId, card_type: 'text', content: inputText, sort_order: computed }` (per D-10)
- Sort order: `Math.max(...cards.map(c => c.sort_order), 0) + 1000`
- On success: invalidate `['classroom-cards', sectionId]`

**3. useCreateLinkCard(sectionId: string)**
- Mutation inserts `{ section_id: sectionId, card_type: 'link', content: url, title: displayTitle, sort_order: computed }` (per D-11)
- On success: invalidate

**4. useCreateFileCard(sectionId: string)**
- Input: `{ fileUri: string, fileName: string, mimeType: string, cardType: 'pdf' | 'image', classroomId: string }`
- MutationFn:
  1. Call `uploadClassroomFile(classroomId, fileUri, fileName, mimeType)` to get `storagePath`
  2. Insert card: `{ section_id: sectionId, card_type: cardType, title: fileName, storage_path: storagePath, sort_order: computed }`
- On success: invalidate

**5. useDeleteCard(sectionId: string)**
- Optimistic delete per D-20:
  - `onMutate`: cancel queries, save previous, remove card from cache
  - `onError`: restore previous
  - `onSettled`: invalidate `['classroom-cards', sectionId]`
- `mutationFn`: `supabase.from('classroom_cards').delete().eq('id', cardId)`
- Note: If card has `storage_path`, also delete from Storage: `supabase.storage.from('classroom-assets').remove([storagePath])`. Do this before deleting the DB row.

**Internal state for text/link forms:**
- `formMode: 'text' | 'link' | null` — toggles between type selection view and inline form view within the sheet
- When `formMode === 'text'`: show multiline TextInput + "Save" Button + "Cancel" link inside the sheet (replaces the four options)
- When `formMode === 'link'`: show URL TextInput + optional title TextInput + "Save" Button + "Cancel" link inside the sheet

**On press handlers — all handled directly inside AddCardBottomSheet:**

- **Text note**: set `formMode = 'text'`. On save: call `useCreateTextCard(sectionId).mutate(text)`, then `onClose()` and reset `formMode`.

- **PDF / File**: call `onClose()`, then call `DocumentPicker.getDocumentAsync({ type: 'application/pdf' })`. If not cancelled, call `useCreateFileCard(sectionId).mutate({ fileUri: result.assets[0].uri, fileName: result.assets[0].name, mimeType: result.assets[0].mimeType || 'application/pdf', cardType: 'pdf', classroomId })`.

- **Link**: set `formMode = 'link'`. On save: call `useCreateLinkCard(sectionId).mutate({ url, title })`, then `onClose()` and reset `formMode`.
