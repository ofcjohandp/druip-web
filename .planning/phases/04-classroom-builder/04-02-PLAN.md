Create `src/features/classroom/useClassroomSections.ts` with these 5 exports:

**1. useClassroomSections(classroomId: string | undefined)**
- Query key: `['classroom-sections', classroomId]` (per D-19)
- Fetches from `classroom_sections` table, filters by `classroom_id`, orders by `sort_order` ascending
- `enabled: !!classroomId`
- Returns `useQuery` result typed as `ClassroomSectionRow[]`

**2. useCreateSection(classroomId: string)**
- Mutation inserts into `classroom_sections` with `{ classroom_id: classroomId, name, sort_order }`
- Compute sort_order from cached query data: `Math.max(...sections.map(s => s.sort_order), 0) + 1000`
- Pass sort_order into the mutation call, not computed inside mutationFn
- On success: `queryClient.invalidateQueries({ queryKey: ['classroom-sections', classroomId] })`

**3. useRenameSection(classroomId: string)**
- Mutation updates `classroom_sections` set `name` where `id` matches
- On success: invalidate `['classroom-sections', classroomId]`

**4. useDeleteSection(classroomId: string)**
- Optimistic delete per D-20:
  - `onMutate`: cancel queries, save previous data, remove section from cache
  - `onError`: restore previous data from context
  - `onSettled`: invalidate `['classroom-sections', classroomId]`
- `mutationFn`: `supabase.from('classroom_sections').delete().eq('id', sectionId)`

**5. useReorderSections(classroomId: string)**
- Optimistic swap per D-05 and D-20:
  - `onMutate`: cancel queries, save previous, swap the two sections in cache array and swap their sort_order values
  - `onError`: restore previous
  - `onSettled`: invalidate
- `mutationFn`: two Supabase update calls to swap sort_order values between sectionA and sectionB (only 2 rows updated, not all)

All hooks import from:
```typescript

import type { Database } from '@/types/database';

```

Use `useAuthStore.getState().session?.user?.id` inside `mutationFn` for one-off auth reads (established pattern from useCreateClassroom.ts). Do NOT use useAuthStore as a hook inside mutationFn.
