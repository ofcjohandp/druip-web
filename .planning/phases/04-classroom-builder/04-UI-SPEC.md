## Color

Source: `src/features/ui/theme.ts` COLORS tokens

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` (`COLORS.background`) | Screen background, ScrollView background, modal overlay background |
| Secondary (30%) | `#FAFAF8` (`COLORS.surface`) | Section card background, card list item background, bottom sheet background |
| Accent (10%) | `#FF6B6B` (`COLORS.accent`) | Primary CTA buttons only — "Add Section" button, "Save" on inline rename confirm |
| Destructive | `#D32F2F` (`COLORS.error`) | Delete section confirmation button, delete card trash icon (active state) |

Supporting values (from theme.ts, used as-is):
- `COLORS.text` (`#1A1A1A`) — all primary text
- `COLORS.textMuted` (`#9E9E9E`) — card count, card preview text, empty state body
- `COLORS.border` (`#EBEBEB`) — section row divider, card list item separator, TextInput border
- `COLORS.textOnAccent` (`#FFFFFF`) — text on accent-colored buttons

Accent reserved for:
1. "Add Section" primary CTA button
2. "Save" confirmation on inline section rename (if explicit save button shown)
3. "Add card" CTA in empty-section state

Accent is NOT used for: ↑ ↓ reorder arrows, gear icon, card type icons in bottom sheet, section name text, card preview text.

## Interaction Contracts

### Section Name — Inline Edit

- State trigger: tutor taps section name text
- Transition: `Text` component replaced with `TextInput` (same position, same font — 20px semibold)
- Confirm: return key or blur saves; calls rename mutation; TextInput reverts to Text
- Cancel: blur without edit (no change) reverts silently
- Saving state: TextInput disabled, opacity 0.6 while mutation in flight
- Error: TextInput border turns `COLORS.error`; error message 14px below input

### Section Reorder — Arrow Buttons

- ↑ button: disabled (opacity 0.4, non-tappable) when section is first in list
- ↓ button: disabled (opacity 0.4, non-tappable) when section is last in list
- On tap: optimistic swap in UI immediately; Supabase `sort_order` update in background
- If Supabase mutation fails: revert to previous order; show inline error toast (14px, `COLORS.error`)

### Section Delete — Confirmation

- Trigger: tutor taps ✕ on section row
- Confirmation: React Native `Alert.alert` with title "Delete section?" and body "This will also delete all [N] cards inside it. This cannot be undone."
- Actions: "Cancel" (dismiss) and "Delete" (`COLORS.error` text on iOS, destructive style)
- On confirm: optimistic removal from list; Supabase cascade delete in background

### Card Delete — Confirmation

- Trigger: tutor taps trash icon on a card list item
- Confirmation: `Alert.alert` with title "Remove card?" and body "This cannot be undone."
- Actions: "Cancel" and "Remove" (destructive style)
- On confirm: optimistic removal; Supabase delete in background

### File Upload — PDF and Image

- Trigger: tutor selects PDF or Image in bottom sheet
- Transition: bottom sheet closes; file picker opens (expo-document-picker / expo-image-picker)
- Upload state: card placeholder appears in section with a progress indicator (ActivityIndicator, `COLORS.accent`) and filename
- Success: placeholder replaced with real CardListItem showing file name
- Failure: placeholder shows error icon + "Upload failed. Tap to retry." (14px, `COLORS.error`)

### Add Section — Empty State

- Shown when: classroom has zero sections
- Layout: vertically centered in scroll area
- Heading: "Build your classroom" (20px semibold, `COLORS.text`)
- Body: "Add your first section to organise your material." (16px, `COLORS.textMuted`)
- CTA: Button variant="primary" title="Add your first section"

### Section with No Cards — Empty State

- Shown when: section exists but has zero cards
- Layout: inside the section card, below section header
- Body: "No material yet. Add your first card." (14px, `COLORS.textMuted`, center-aligned)
- CTA: Ghost text button "+ Add card" (accent color text)

## Destructive Actions

| Action | Trigger | Confirmation Method | Irreversible |
|--------|---------|---------------------|--------------|
| Delete section (+ all its cards) | ✕ icon on SectionRow | `Alert.alert` — two-button, destructive style | Yes |
| Delete card | Trash icon on CardListItem | `Alert.alert` — two-button, destructive style | Yes |

No swipe-to-delete. Single tap → confirmation → execute. Source: CONTEXT.md D-07, D-13.

## Loading and Error States

| State | Component | Visual Treatment |
|-------|-----------|-----------------|
| Initial sections load | ManageClassroomScreen | ActivityIndicator centered, `COLORS.accent` color |
| Section rename saving | Inline TextInput | Opacity 0.6, disabled |
| Section reorder saving | SectionRow | Optimistic — no loading indicator (instant feel) |
| Card upload in progress | CardListItem placeholder | ActivityIndicator + filename, `COLORS.textMuted` |
| Card upload failed | CardListItem error | Error icon + "Upload failed. Tap to retry." text |
| Sections fetch failed | ManageClassroomScreen | Centered error text + retry button (ghost variant) |
