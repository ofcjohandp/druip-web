## Spacing Scale

Declared values from `src/features/ui/theme.ts` (source of truth — do not hardcode):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 8px | `SPACING.xs` — tight gaps, icon-to-text, card list item internal gaps |
| sm | 12px | `SPACING.sm` — small element gaps, button vertical padding. **Exception: sm: 12px — existing project token in theme.ts; in use across Phases 1–4; cannot be changed without breaking existing screens** |
| md | 16px | `SPACING.md` — default card internal padding, screen horizontal padding |
| lg | 24px | `SPACING.lg` — between major sections, scroll content padding |
| xl | 32px | `SPACING.xl` — large layout gaps, bottom scroll padding |

Exceptions:
- Touch targets (back button, icon buttons): minimum 44x44pt — enforced with `minWidth: 44, minHeight: 44` on the wrapping `TouchableOpacity`. Source: established pattern in `manage-classroom.tsx` `backButton` style.
- Lock icon overlay: semi-transparent overlay uses 0.85 opacity on `COLORS.surface` background — no spacing exception.

## Typography

All font sizes are React Native `fontSize` values. No custom font family — system fonts only.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 (normal) | 1.5 (system default) | Tutor bio excerpt, card body text, section names, confirmation screen body copy |
| Label | 14px | 400 (normal) | 1.4 | Subject tags, price badge, muted meta text (e.g. "3 sections"), locked indicator text |
| Heading | 20px | 600 (semibold) | 1.2 | Screen header titles, classroom name in detail page, classroom name in card |
| Display | 28px | 600 (semibold) | 1.2 | Subscribe confirmation screen — classroom name (prominent single-focus layout) |

Source: heading/body sizes verified against existing `manage-classroom.tsx` styles (`headerTitle: fontSize 20, fontWeight 600`; `emptyHeading: fontSize 20, fontWeight 600`; `emptyBody: fontSize 16`; `errorText: fontSize 16`).

## Color

All values from `src/features/ui/theme.ts`. No hardcoded hex values in new components.

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | `COLORS.background` | #FFFFFF | Screen background for all three new screens (Home/Discovery, Classroom Detail, Subscribe Confirm) |
| Secondary (30%) | `COLORS.surface` | #FAFAF8 | ClassroomCard background, "Your Classrooms" section header background, locked content overlay fill, section rows on detail page |
| Accent (10%) | `COLORS.accent` | #FF6B6B | Reserved list below — nowhere else |
| Destructive | `COLORS.error` | #D32F2F | Not used in this phase (no destructive actions) |

Accent (`#FF6B6B`) is reserved exclusively for:
1. Subscribe primary CTA button background (`Button variant="primary"`)
2. Subscribe CTA on classroom detail page — the single affordance that drives conversion
3. `ActivityIndicator` color during loading states
4. "Your Classrooms" section header accent dot or left-border indicator (1 decorative use)

Accent is NOT used on: navigation icons, section names, price labels, back buttons, card borders, tags, or any informational text.

Additional semantic values:
- `COLORS.text` (#1A1A1A) — all primary readable text
- `COLORS.textMuted` (#9E9E9E) — bio excerpt, section count, lock label, "Maybe later" button text
- `COLORS.border` (#EBEBEB) — card bottom borders, section dividers, header bottom border
- `COLORS.textOnAccent` (#FFFFFF) — text inside accent-colored buttons

**Focal points:**
- Primary focal point: the ClassroomCard list on the Home/Discovery screen.
- Secondary focal point: the Subscribe CTA button (accent) on the detail and confirmation screens.

## Component Inventory

New components to create for this phase. All must import tokens from `src/features/ui/theme.ts` only.

### ClassroomCard (`src/features/student/ClassroomCard.tsx`)

Displays a single classroom in the discovery list.

Layout (vertical, top to bottom):
1. Classroom name — Heading (20px, 600, `COLORS.text`)
2. Tutor name — Label (14px, 400, `COLORS.textMuted`)
3. Subject tags — horizontal row of pill tags (14px, 400, `COLORS.textMuted`, `COLORS.surface` background, `COLORS.border` border, `RADII.button` radius, `SPACING.xs` vertical padding, `SPACING.sm` horizontal padding)
4. Bio excerpt — Body (16px, 400, `COLORS.textMuted`) — truncated to 2 lines (`numberOfLines={2}`)
5. Price — Label (14px, 600, `COLORS.text`) — displayed as `R${price_cents / 100}/month`

Container: `COLORS.surface` background, `RADII.card` (16px) border radius, `SPACING.md` (16px) internal padding, `SPACING.sm` (12px) bottom margin between cards. No shadow — border only (`COLORS.border`, 1px width).

Interaction: `TouchableOpacity` with `activeOpacity={0.8}`. Full card is tappable. Navigates to `/(tabs)/classroom-detail?id={classroomId}`.

### LockedContentOverlay (`src/features/student/LockedContentOverlay.tsx`)

Shown over each section row on the detail page when `isSubscribed === false`.

Layout:
- Wraps a section name row with a semi-transparent overlay (`COLORS.surface` at 0.85 opacity via `rgba(250, 250, 248, 0.85)`)
- Lock icon: `Ionicons name="lock-closed-outline"` size={16} color={`COLORS.textMuted`} — inline left of the section name
- Section name text: Label (14px, 400, `COLORS.textMuted`) — no line-through, just muted

The overlay does NOT block the section name from being readable — section titles are visible as a teaser per D-06/D-07.

### "Your Classrooms" Section Header

Not a standalone component — implemented inline in `index.tsx`.

- Section label: "Your Classrooms" — Label (14px, 600, `COLORS.textMuted`) with 4px left border using `COLORS.accent`
- Padding: `SPACING.md` horizontal, `SPACING.sm` vertical
- Background: `COLORS.background` (no surface tint on the label row itself)
- Bottom margin before classroom list: `SPACING.sm`

## Screen Contracts

### Screen 1: Home / Discovery (`src/app/(tabs)/index.tsx`)

Structure:
```
SafeAreaView (COLORS.background)
  ScrollView
    [if subscriptions.length > 0]
      "Your Classrooms" section header
      FlatList / map of ClassroomCard (subscribed classrooms only)
      Divider (1px, COLORS.border, SPACING.lg vertical margin)
    "Browse Classrooms" section header (same style as above)
    [if isLoading]  ActivityIndicator (COLORS.accent, large, centered)
    [if isError]    Error state (see Copywriting)
    [if data.length === 0 and !isLoading]  Empty state (see Copywriting)
    [if data.length > 0]  map of ClassroomCard
```

Padding: `SPACING.lg` (24px) horizontal on scroll content. `SPACING.xl` (32px) bottom padding.

### Screen 2: Classroom Detail (`src/app/(tabs)/classroom-detail.tsx`)

Structure:
```
SafeAreaView (COLORS.background)
  Header row: back arrow (arrow-back, 24px, COLORS.text, 44x44 touch) + screen title "Classroom"
  ScrollView (SPACING.md padding)
    Classroom name — Heading (20px, 600)
    Tutor name — Label (14px, 400, COLORS.textMuted)
    Subject tags — horizontal pill row
    Bio — Body (16px, 400, COLORS.text) full text, no truncation
    Price — Body (16px, 600, COLORS.text) "R180/month"
    Divider (COLORS.border)
    "Sections" subheading — Label (14px, 600, COLORS.textMuted), SPACING.sm top margin
    [for each section]
      Section row: lock icon (if !isSubscribed) + section name, COLORS.surface background, RADII.button radius, SPACING.sm padding, SPACING.xs gap between rows
    [if isSubscribed]
      Cards shown inline inside each section (CardListItem reuse)
    Spacer (SPACING.xl)
    [if !isSubscribed]
      Subscribe CTA Button (variant="primary", full width, "Subscribe · R{price}/month")
    [if isSubscribed]
      "You're subscribed" confirmation label (Label, 14px, COLORS.textMuted, centered) + checkmark icon (checkmark-circle, 16px, COLORS.success)
```

Subscribe CTA is pinned at bottom of scroll, not fixed — scrolls with content.

### Screen 3: Subscribe Confirmation (`src/app/(tabs)/subscribe-confirm.tsx`)

Structure:
```
SafeAreaView (COLORS.background)
  Header row: back arrow (arrow-back, 24px) + screen title "Subscribe"
  View (flex: 1, justifyContent: center, paddingHorizontal: SPACING.lg)
    Classroom name — Display (28px, 600, COLORS.text, textAlign: center)
    Tutor name — Label (14px, 400, COLORS.textMuted, textAlign: center, marginTop: SPACING.xs)
    Price — Heading (20px, 600, COLORS.text, textAlign: center, marginTop: SPACING.md)
    Copy block — Body (16px, 400, COLORS.textMuted, textAlign: center, marginTop: SPACING.sm)
    Subscribe button — Button variant="primary", full width, marginTop: SPACING.lg
    "Maybe later" button — Button variant="ghost", full width, marginTop: SPACING.sm
```

| Element | Copy |
|---------|------|
| Primary CTA — subscribe | `Subscribe · R{price}/month` |
| Confirmation screen — confirm button | `Subscribe` |
| Confirmation screen — cancel | `Maybe later` |
| Confirmation screen — body | `You'll get full access to all sections and materials in this classroom.` |
| Discovery empty state heading | `No classrooms yet` |
| Discovery empty state body | `Check back soon — tutors are setting up their classrooms.` |
| Discovery error state | `Couldn't load classrooms. Pull down to refresh.` |
| Detail page loading | ActivityIndicator only — no text label |
| Detail page error | `Couldn't load this classroom. Go back and try again.` |
| Subscribed indicator | `You're subscribed` |
| Lock indicator (accessibility label) | `Locked — subscribe to access` |
| "Your Classrooms" section header | `Your Classrooms` |
| "Browse Classrooms" section header | `Browse Classrooms` |
| Subscribe confirmation screen copy guidelines | Calm and low-pressure. No urgency words ("now", "limited", "don't miss"). No exclamation marks. No marketing superlatives. Source: D-11, CONTEXT.md Specifics. |

Destructive actions in this phase: none. No confirmation dialogs required.

## Interaction States

All interactive states must be implemented. No state can be left undefined.

| State | Element | Implementation |
|-------|---------|----------------|
| Loading | Discovery list | `ActivityIndicator` size="large" color={COLORS.accent} centered in available space |
| Loading | Detail page | `ActivityIndicator` size="large" color={COLORS.accent} centered |
| Loading | Subscribe mutation (isPending) | Subscribe button `disabled={mutation.isPending}`, opacity 0.6 via `disabled` prop |
| Error | Discovery list | Inline error text (Body, COLORS.textMuted) + "Retry" ghost button |
| Error | Detail page | Inline error text + back button suggestion |
| Empty | Discovery list (no classrooms) | Centered empty state — heading + body (see Copywriting) |
| Empty | "Your Classrooms" section | Section is hidden entirely when `subscriptions.length === 0` — not shown with empty state |
| Subscribed | Detail page | Subscribe CTA replaced with "You're subscribed" + checkmark |
| Pressed | ClassroomCard | `activeOpacity={0.8}` |
| Pressed | Back button | `activeOpacity={0.7}` — consistent with `manage-classroom.tsx` pattern |
