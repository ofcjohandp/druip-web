## Spacing Scale

All values are multiples of 4. These map directly to Tailwind spacing units already in use.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge internal padding |
| sm | 8px | Inline element gaps (avatar + label, icon + text) |
| md | 16px | Default padding inside cards, button horizontal padding |
| lg | 24px | Section horizontal padding (`px-6`), card internal padding (`p-6`) |
| xl | 32px | Card large padding (`p-8`), grid gaps |
| 2xl | 48px | Section vertical margin (`mb-12`) |
| 3xl | 64px | — reserved, not used in this phase |

Exceptions:
- Top app bar: `py-4 px-6` (16px vertical, 24px horizontal) — matches Stitch header spec
- Bottom nav: `pb-6 px-4` with active item `-translate-y-2` lift — matches Stitch nav spec
- Main content area: `pt-24 pb-32` accounts for fixed header and bottom nav
- Touch targets (bottom nav icons): 40px minimum (`w-10 h-10`) for accessibility

## Typography

All sizes and weights are extracted from the existing `home/page.tsx` and Stitch reference (`home_dashboard/code.html`). Do not deviate.

| Role | Size | Weight | Line Height | Font | Class |
|------|------|--------|-------------|------|-------|
| Display (hero heading) | 56px (3.5rem) | 800 (extrabold) | 1 (leading-none) | Plus Jakarta Sans | `font-headline text-[3.5rem] font-extrabold leading-none tracking-tight` |
| Heading (section titles) | 24px (1.5rem) | 700 (bold) | 1.2 | Plus Jakarta Sans | `font-headline text-2xl font-bold` |
| Card title | 18–20px | 700 (bold) | 1.3 | Plus Jakarta Sans | `font-headline text-3xl font-bold` (spotlight card) / `font-bold text-lg` (list cards) |

Maximum 4 sizes in use. Heading weight is always 700+; body weight is always 400.

## Color

All tokens are defined in `tailwind.config.ts`. Use token names, not raw hex values, in all new code.

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | `bg-surface` / `bg-background` | #f5f6f7 | Page background, full-width areas |
| Secondary (30%) | `bg-surface-container-low` / `bg-surface-container-lowest` | #eff1f2 / #ffffff | Cards, bottom nav, frosted-glass header |
| Accent (10%) | `bg-primary` / `text-primary` | #0058bb | See accent reserved-for list below |
| Secondary accent | `bg-secondary-container` | #ffca4d | Streak card background only |
| Tertiary accent | `bg-tertiary-container` / `text-on-tertiary-container` | #ff9475 | Badge labels ("Upcoming Session", "NEW STAR") only |
| Destructive | `bg-error` | #b31b25 | Not used in this phase |

Accent (`primary` #0058bb) reserved for:
1. Active bottom nav icon and label
2. "Go to Classroom" CTA button (kinetic-gradient variant: `linear-gradient(135deg, #0058bb 0%, #6c9fff 100%)`)
3. "Browse Tutors" / "Browse Classrooms" CTA button in empty states
4. Text links ("View All" — disabled in this phase, styled `text-primary`)
5. Druip wordmark in header
6. Progress bar fill in Continue Learning cards

Secondary accent (`secondary-container` #ffca4d) reserved for: streak card background only.

Tertiary accent (`tertiary-container` #ff9475) reserved for: pill badges on cards only.

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Page load | Single server render — all queries run in parallel via `Promise.all` before render |
| Suspense boundaries | Wrap Tutors section and Continue Learning section independently so a slow query does not block the whole page |
| Loading state | Skeleton shimmer: `animate-pulse bg-surface-container-high rounded` at same dimensions as live content |
| Hover — tutor card | `shadow-sm` to `shadow-md` transition (`transition-shadow`) |
| Hover — continue learning card | `scale-[1.02]` transform (`transition-transform hover:scale-[1.02]`) |
| Hover — CTA button | `hover:opacity-90` for gradient buttons; `active:scale-95` for all buttons |
| "View All" | Disabled — render as text `text-outline` (not `text-primary`), no click handler |
| "Book a Session" | Disabled — render as `bg-surface-container-high text-outline`, no click handler |
| Bottom nav active state | Home tab only: `bg-primary text-white rounded-full p-3 -translate-y-2 scale-110` |

## Data Fetching Contract

This phase keeps the dashboard as a single async Server Component. The following parallel query pattern is required.

```
Promise.all([
  supabase.from("profiles").select("streak_count").eq("id", user.id).single(),
  supabase.from("subscriptions").select("*, classrooms(*)").eq("user_id", user.id).order("updated_at", { ascending: false }),
  supabase.from("tutors" /* or equivalent */).select("*").order("created_at", { ascending: false }).limit(4),
])
```

The planner must verify the exact table and column names against the live Supabase schema before implementing. If `profiles.streak_count` does not exist, default to 0 and flag in the plan.
