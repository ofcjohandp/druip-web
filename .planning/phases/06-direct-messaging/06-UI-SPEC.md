## Spacing Scale

Declared values — sourced directly from `src/features/ui/theme.ts` (SPACING tokens):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 8px | Tight inline gaps — timestamp below bubble, icon-to-text gap in send row |
| sm | 12px | Small gaps — padding inside bubble, gap between consecutive bubbles |
| md | 16px | Default padding — screen horizontal padding, input container padding |
| lg | 24px | Section breaks — gap between header and first message, above input bar |
| xl | 32px | Large spacing — bottom safe area pad beneath input bar |

Exceptions:
- Touch targets (back button, send button, subscriber list rows): minimum 44×44pt per iOS HIG. Source: established in classroom-detail.tsx `backButton` style.
- Chat bubble max-width: 75% of screen width — prevents full-width bubbles that break the iMessage layout convention.
- Input bar bottom padding: accounts for KeyboardAvoidingView offset; uses `behavior="padding"` on iOS, `behavior="height"` on Android.

## Interaction Contracts

### Send Message

1. User types in TextInput. Send button becomes active (opacity 1.0) when input.trim().length > 0.
2. User taps Send. Input clears immediately (optimistic clear). Message appears at bottom of list.
3. `useSendMessage` mutation fires. On error: restore input text, show inline error below input ("Couldn't send. Try again.").
4. No "sending…" optimistic bubble — wait for confirmation then invalidate query. Source: Claude discretion, keeps complexity low for v1.0.

### Pull-to-Refresh

- Standard `RefreshControl` on FlatList. `tintColor: COLORS.accent`.
- On refresh complete: list scrolls to end.

### Keyboard Avoidance

- Wrap entire screen in `KeyboardAvoidingView`.
- `behavior="padding"` on iOS, `behavior="height"` on Android.
- Input bar always visible above keyboard.

### "Message tutor" Entry (Student Side)

- Button appears in `classroom-detail.tsx` below the "You're subscribed" indicator.
- `variant="secondary"` — does not compete with the subscribe CTA visual weight.
- Label: "Message tutor" (see Copywriting Contract).
- Hidden entirely for non-subscribers (conditional render, not opacity/disabled).

### Subscriber List (Tutor Side)

- Each `SubscriberRow` is a `TouchableOpacity` (`minHeight: 52px`, `activeOpacity: 0.7`).
- Unread dot: shown when there is at least one message where `sender_id !== tutorId` and the tutor has not replied yet. Implementation: Claude discretion — simplest heuristic is last message sender is not the tutor. Dot is 8px circle, `COLORS.accent`, `position: absolute, right: SPACING.md`.
- On tap: `router.push('/(tabs)/dm-chat?classroomId=X&studentId=Y')`.
