## Spacing Scale

All tokens sourced from `src/features/ui/theme.ts` (SPACING). No new tokens introduced this phase.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 8pt | Icon gaps, tight inline padding |
| sm | 12pt | Gap between answer option cards |
| md | 16pt | Padding inside cards, button padding |
| lg | 24pt | Progress bar bottom margin, section padding |
| xl | 32pt | Large vertical gaps between question and options |

Exceptions:
- Progress bar height: 6pt (visual affordance, not a spacing token)
- Touch target minimum: 48pt height on all tappable answer options and buttons (STUDY-08; matches Android 48dp minimum)
- `hitSlop` on elements whose visual size falls below 44pt: `{ top: 8, bottom: 8, left: 8, right: 8 }`

## Color

All tokens sourced from `src/features/ui/theme.ts` (COLORS).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` | Screen background, question card background |
| Secondary (30%) | `#FAFAF8` | Answer option cards (pre-answer state), feedback panel background, topic cards, lesson list items |
| Accent (10%) | `#FF6B6B` | See reserved list below |
| Correct (semantic) | `#388E3C` (border/icon) + `#E8F5E9` (fill) | Correct answer highlight on selected and on correct-option reveal |
| Incorrect (semantic) | `#D32F2F` (border/icon) + `#FFEBEE` (fill) | Wrong answer highlight on selected wrong option only |
| Text primary | `#1A1A1A` | All primary text |
| Text muted | `#9E9E9E` | Explanation text, secondary labels, locked lesson text |
| Border | `#EBEBEB` | Subtle card borders, dividers |
| Text on accent | `#FFFFFF` | Text on accent-colored buttons |

Accent (`#FF6B6B`) reserved for:
1. Progress bar fill (advances as student answers questions)
2. Continue / primary CTA button background
3. Active tab indicator in the bottom tab bar (inherited from Phase 1)
4. Current/next-unlocked lesson highlight border in the lesson list

Accent is NOT used on answer options in any state. Correct answers use green (`#388E3C`). Wrong answers use red (`#D32F2F`).

Locked lesson items: text in `#9E9E9E`, lock icon in `#9E9E9E`. No red — locked is neutral, not an error.

## Component Inventory

Components Phase 2 must produce or extend. All import from `theme.ts` — no hardcoded values.

### Question Card
- Single card render (no FlatList). Swaps on answer advance.
- Full-width, `flex: 1`, `padding: SPACING.lg`.
- Question text at top: 20pt semibold, `marginBottom: SPACING.lg`.
- Progress bar: 6pt height, `COLORS.accent` fill, `COLORS.surface` track, `borderRadius: 3`, `marginBottom: SPACING.xl`.

### Answer Option
- `backgroundColor: COLORS.surface`, `padding: SPACING.md`, `borderRadius: RADII.card` (16pt).
- `marginBottom: SPACING.sm` (12pt gap between options).
- `minHeight: 48` (STUDY-08).
- Pre-answer: no border. Post-answer: 2pt border in semantic color.
- Correct state: `backgroundColor: '#E8F5E9'`, `borderColor: COLORS.success`, checkmark icon (Ionicons `checkmark-circle`) at trailing end.
- Wrong state (selected only): `backgroundColor: '#FFEBEE'`, `borderColor: COLORS.error`, X icon (Ionicons `close-circle`) at trailing end.
- Unselected wrong options post-answer: no change (remain in default surface state).
- Color + icon feedback must apply within 150ms of tap (STUDY-04). Use `useState` + synchronous `setIsLocked(true)` — no async gap.

### Feedback Panel
- Slide-up from bottom of screen.
- `borderTopLeftRadius: RADII.modal` (24pt), `borderTopRightRadius: RADII.modal`.
- `backgroundColor: COLORS.surface`.
- Animation: spring with `useNativeDriver: true`, friction 8, tension 40.
- Panel height: content-driven with `padding: SPACING.lg`.
- Correct state: single reinforcement line (16pt regular, `COLORS.text`) + Continue button.
- Wrong state: "Correct answer: [option text]" in 14pt semibold + explanation in 14pt regular `COLORS.textMuted` + Continue button.
- Continue button: full-width, `backgroundColor: COLORS.accent`, `minHeight: 48`, `borderRadius: RADII.button` (12pt).
- Manual tap only — no auto-advance (STUDY-06).

### Topic Card (Study tab)
- `backgroundColor: COLORS.surface`, `borderRadius: RADII.card`, `padding: SPACING.md`.
- Topic name: 16pt semibold.
- Readiness tier label: 14pt regular `COLORS.textMuted`.
- Lesson count: 14pt regular `COLORS.textMuted` ("3 of 8 lessons done").
- No progress bar on the card — tier label is the readiness signal (D-02).

### Lesson List Item
- Unlocked: 16pt regular `COLORS.text`, full opacity.
- Completed: 16pt regular `COLORS.textMuted` + trailing checkmark (Ionicons `checkmark-circle`, `COLORS.success`).
- Current/next: full opacity + 2pt left border or subtle `COLORS.accent` left accent line (D-04).
- Locked: 16pt regular `COLORS.textMuted`, opacity 0.5 + trailing lock icon (Ionicons `lock-closed`, `COLORS.textMuted`). Tapping locked lesson: no navigation, no toast (visual dead end, D-03).
- `minHeight: 48` (STUDY-08).

### Lesson-Complete Screen
- Full screen (not modal), `backgroundColor: COLORS.background`.
- XP earned: 28pt semibold `COLORS.text`, centered. Label above: 14pt regular `COLORS.textMuted` ("XP earned").
- Score summary: 16pt regular `COLORS.text`, centered ("12 of 15 correct").
- Streak count: 16pt regular `COLORS.text` ("Current streak: N days").
- Primary CTA: full-width `backgroundColor: COLORS.accent` button, "Continue", 16pt semibold `COLORS.textOnAccent`, `minHeight: 48`.
- Tone: calm — no confetti, no animated explosions (D-10).

## Interaction Contracts

### Answer Tap Lock (STUDY-04)
- `TouchableOpacity` with `activeOpacity: 0.7`.
- On press: synchronously call `setIsLocked(true)` and `setSelectedOption(index)` in the same handler.
- Color + icon state is derived from render — no async delay.
- Total time from tap to visual feedback: within 150ms (React Native synchronous state update is within one frame at 60fps).
- `disabled={isLocked}` on all option `TouchableOpacity` elements after lock.

### Progress Bar Advance (STUDY-02)
- Progress fraction: `(currentIndex + (isLocked ? 1 : 0)) / totalQuestions`.
- Bar never shrinks. Advances immediately when `isLocked` becomes `true`.
- Width transition: no animation — immediate update (avoids perceived latency).

### Feedback Panel Slide-Up (D-05)
- Trigger: `isLocked === true`.
- Animation: `Animated.spring` from off-screen bottom to visible position.
- `useNativeDriver: true` required.
- Spring config: `friction: 8`, `tension: 40`.

### Lesson Complete Navigation (D-09)
- Tapping "Continue" on lesson-complete screen: `router.replace('/(tabs)/study/[topicId]')` — replace not push, so back gesture does not return to a completed lesson session.

### Touch Targets (STUDY-08)
- `minHeight: 48` on answer options and all buttons.
- `hitSlop={{ top: 8, bottom: 8, left: 8, right: 8 }}` on any icon-only or small tappable element.
