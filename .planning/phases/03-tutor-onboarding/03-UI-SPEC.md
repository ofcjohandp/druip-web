## Spacing Scale

All values sourced from `src/features/ui/theme.ts` (SPACING constant). Declared values are multiples of 4:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 8px | Icon gaps, tag chip internal padding, input prefix gap |
| sm | 12px | Small element gaps (e.g. gap between form label and input) |
| md | 16px | Default card padding, form field padding, minimum inside all cards |
| lg | 24px | Between major form sections, between toggle and password field |
| xl | 32px | Layout vertical rhythm, bottom CTA bottom margin |

Exceptions: Touch targets (toggle, tag remove button, form CTA) use minimum height 48px per `Button` component `base` style — this is a touch-target constraint, not a spacing token.

Note: The existing SPACING scale in theme.ts starts at `xs: 8` (not 4). No 4px token exists. Do not introduce a 4px value — use `xs: 8` as the smallest unit.

|------|------|--------|-------------|

Form section helper text / validation errors: 14px / weight 400 / COLORS.error.

## Color

All values sourced from `src/features/ui/theme.ts` (COLORS constant).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` | Screen backgrounds, ScrollView background |
| Secondary (30%) | `#FAFAF8` | Card surfaces (Card component), input backgrounds, tag chip background |
| Accent (10%) | `#FF6B6B` | Primary CTA button fill ("Create classroom", "Save changes"), active tab icon, toggle thumb when ON |
| Destructive | `#D32F2F` | Inline validation error text only — no destructive actions in Phase 3 |

Accent reserved for:
1. Primary CTA button background ("Create classroom" and "Save changes")
2. Toggle thumb fill when the "I want to teach" toggle is in ON state
3. Active Expo vector icon in bottom tab bar (inherited from Phase 1)

Accent is NOT used for: input borders, card borders, label text, secondary buttons, or ghost buttons.

Border color for inputs and cards: `#EBEBEB` (COLORS.border).
Disabled state: opacity 0.6 on the primary CTA (matches existing Button `disabled` style).
Toggle track (ON): use a tinted version of accent at 30% opacity — `rgba(255, 107, 107, 0.3)`. Toggle track (OFF): `#EBEBEB`.

Source: Phase 1 CONTEXT.md D-10, D-11; theme.ts COLORS.

## Component Inventory

These are the specific UI components required for Phase 3. All reuse existing tokens.

### 1. "I Want to Teach" Toggle (new)

Placement: `sign-up.tsx`, below password field, above the primary CTA.
Component type: React Native `Switch` component.
- Track color OFF: `#EBEBEB`
- Track color ON: `rgba(255, 107, 107, 0.3)`
- Thumb color: `#FF6B6B` (ON) / `#FFFFFF` (OFF)
- Label: "I want to teach" — 16px / weight 400 / COLORS.text, inline left of the switch
- Sub-label: "Create a classroom for your students" — 14px / weight 400 / COLORS.textMuted, below the label
- Layout: label + sub-label stacked left, Switch right-aligned (row with justifyContent: 'space-between')
- Container: Card component (COLORS.surface background), SPACING.md padding, RADII.card border radius
- Visual weight: secondary — the card uses COLORS.surface (not white) to visually distinguish from the form fields above it without competing with them

### 2. Subject Tag Input (new)

Placement: classroom creation form and classroom settings form.
Structure:
- TextInput row: plain text input with "Add subject" placeholder + "Add" ghost button inline right
- Tag chips row: wrapping flexbox row below the input, renders one chip per subject
- Chip anatomy: COLORS.surface background, COLORS.border border (1px), RADII.button (12px) border radius, 8px horizontal padding, 6px vertical padding
- Chip text: 14px / weight 400 / COLORS.text
- Chip remove button: Expo vector icon `close` at 14px / COLORS.textMuted, 4px left margin from text, minimum touch target 24x24px
- "Add" inline button: ghost variant using existing Button component, label "Add", triggers adding the current TextInput value as a tag

### 3. Classroom Creation Form Screen (new)

Route: `src/app/(auth)/create-classroom.tsx`
Layout: KeyboardAvoidingView > ScrollView > form content > CTA pinned to bottom.
Fields in order:
1. "Classroom name" — TextInput, placeholder "e.g. Physio Year 2 — Cardiopulmonary"
2. "Subjects" — Subject Tag Input component (see above)
3. "Bio" (optional) — multiline TextInput, placeholder "Tell students what you cover and how you teach", minHeight 96px
4. "Monthly price" — single-line TextInput with "R" prefix, keyboard type numeric, default value "180"

Section spacing: SPACING.lg (24px) between each field group.
Field label: 14px / weight 400 / COLORS.textMuted, 8px below label to input.
Screen header: title "Create your classroom", back arrow (ghost) — but back is intentionally hidden on this screen since the tutor path has no valid back destination during sign-up. On the settings re-entry path, back arrow is shown.

CTA: Button variant="primary", title="Create classroom", full width, SPACING.md margin bottom. Disabled when classroom name is empty OR subjects list is empty OR price is empty.

### 4. Profile Tab — Tutor View (modify existing)

Route: `src/app/(tabs)/profile.tsx` — conditional render based on `isTutor` flag.
Tutor-specific element: "My Classroom" card.
- Card component (COLORS.surface, RADII.card 16px, SPACING.md padding)
- Row layout: Expo vector icon `school` (or `book-outline`) at 24px / COLORS.accent left, text block center-flex, chevron icon `chevron-forward` at 18px / COLORS.textMuted right
- Primary text: classroom name — 16px / weight 600 / COLORS.text
- Secondary text: "Manage your classroom" — 14px / weight 400 / COLORS.textMuted
- onPress: navigate to classroom settings screen
- Placement: top of Profile tab content, above any existing profile fields

### 5. Classroom Settings Screen (new)

Route: `src/app/(tabs)/classroom-settings.tsx` (or pushed from Profile tab).
Layout: identical to classroom creation form, but all fields pre-filled with current values.
CTA: Button variant="primary", title="Save changes", full width.
Back arrow: shown — tutors can cancel without saving (no confirmation dialog needed for MVP, per D-10).

## Interaction States

| Component | States |
|-----------|--------|
| "I want to teach" toggle | off (default), on (accent thumb) |
| "Add" subject button | default, pressed (opacity 0.8 via activeOpacity) |
| Tag chip remove ✕ | default, pressed (opacity 0.8) |
| "Create classroom" CTA | default (accent), disabled (opacity 0.6), loading (opacity 0.6 + ActivityIndicator replaces text) |
| "Save changes" CTA | default (accent), disabled (opacity 0.6), loading (opacity 0.6 + ActivityIndicator replaces text) |
| "My Classroom" card | default (COLORS.surface), pressed (opacity 0.85 via TouchableOpacity activeOpacity) |
| Form TextInput | default (COLORS.border), focused (COLORS.accent border, 1px), error (COLORS.error border, 1px + error text below) |

Loading state for CTAs: replace button title text with a small `ActivityIndicator` (size "small", color COLORS.textOnAccent). Button remains full width and disabled during loading.
