<threat_model>
## Threat Model — Plan 02: Sign-up Toggle + Create Classroom

| Threat | Severity | Mitigation |
|--------|----------|------------|
| Root navigator guard race: session fires before create-classroom route resolves | HIGH | Add `pendingTutorOnboarding` boolean to useAuthStore; root guard skips redirect when flag is true |
| User sets is_tutor=true via direct Supabase API without creating a classroom | MEDIUM | RLS on profiles allows update of own row only; is_tutor=true without a classroom record just shows empty profile — no privilege escalation |
| Price input accepts non-numeric or negative values | MEDIUM | TextInput keyboardType="numeric"; parseInt with fallback to 18000; server-side DEFAULT 18000 as safety net |
| Empty subjects array bypasses validation | LOW | CTA disabled check: `subjects.length === 0`; server-side DEFAULT '{}' prevents null |
</threat_model>
